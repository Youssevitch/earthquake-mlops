# Earthquake Tsunami MLOps (On-Prem)

![CI](https://github.com/USER/REPO/actions/workflows/ci.yaml/badge.svg)


End-to-end on-prem MLOps pipeline: data versioning (DVC), training (scikit-learn),
serving (FastAPI), monitoring (Evidently), experiment tracking (MLflow), and
automated retraining (Airflow/cron in later steps).
